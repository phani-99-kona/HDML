# NestFinder - Property Discovery Platform
Academic project built with HTML, CSS and JavaScript (no frameworks, no backend).

## Run
Open `index.html` in any modern browser.

## Files
- index.html - page structure
- style.css  - styling (responsive, light/dark theme)
- script.js  - data, filters, favorites, comparison, inquiry form

## Features
Property listings, generated photo gallery, specifications, location/city filter,
advanced filters and sorting, favorites (localStorage), compare up to 3 properties,
inquiry form with validation (saved to localStorage).
